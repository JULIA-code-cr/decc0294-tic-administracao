# Tutorial Básico de Markdown

Este é um guia rápido para aprender os conceitos básicos do Markdown.

## O que é Markdown?

Markdown é uma linguagem de marcação leve usada para formatar texto de forma simples e legível.

## Títulos

```markdown
# Título 1
## Título 2
### Título 3
```

## Ênfase

- **Negrito**: `**texto**`
- *Itálico*: `*texto*`
- ~~Tachado~~: `~~texto~~`

## Listas

Lista não ordenada:

```markdown
- Item 1
- Item 2
- Item 3
```

Lista ordenada:

```markdown
1. Primeiro
2. Segundo
3. Terceiro
```

## Links e Imagens

```markdown
[Texto do link](https://exemplo.com)
![Descrição da imagem](url-da-imagem.png)
```

## Código

Código inline: `` `código` ``

Bloco de código:

````markdown
```javascript
console.log("Olá, mundo!");
```
````

## Citações

```markdown
> Esta é uma citação.
```

## Tabelas

```markdown
| Nome  | Idade |
|-------|-------|
| Ana   | 25    |
| Bruno | 30    |
```

## Conclusão

Com esses elementos básicos, você já consegue criar documentos bem formatados em Markdown!
